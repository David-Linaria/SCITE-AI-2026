# SCITE-AI-2026

A personal study repository for preparing for the **2026 Shanghai College Information Technology Proficiency Examination — Artificial Intelligence Technology and Applications (Levels 2 & 3)**.

This repository documents my learning journey through Python-based data analysis, machine learning, and artificial intelligence. It includes study notes, hands-on experiments, coding exercises, and exam review materials.

## Repository Structure

```text
SCITE-AI-2026/
├── exam-requirements/   # Official exam syllabus and sample questions
├── notes-modules/       # Jupyter notebooks for Python libraries and AI experiments
├── notes-review/        # Concept summaries and revision notes
├── practice/            # Python exercises and experimental scripts
├── .gitignore           # Git ignore rules
├── README.md            # Project overview
└── requirements.txt     # Python dependencies
```
